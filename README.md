## Featured projects

### [RoadVision AI](https://github.com/Anass-Erf/RoadVision-AI)

Road-damage detection with a fine-tuned YOLO26n model and an inspection workspace for annotations, filters, and exports.

- **Stack:** Python · Ultralytics YOLO · FastAPI · Next.js · TypeScript
- **Engineering:** Validates uploaded images and serializes model access; a busy inference service returns a retryable response instead of queuing requests indefinitely.

### [Ru'ya RAG](https://github.com/Anass-Erf/Ru-ya-RAG)

Arabic historical-text retrieval with original PDF page citations and optional AI summaries. A local research application with limited reviewed corpus coverage.

- **Stack:** Python · Sentence Transformers · FAISS · BM25 · FastAPI · Next.js · DeepSeek
- **Engineering:** Combines lexical and semantic retrieval; checks generated source IDs and exact quotations against supplied excerpts before displaying summaries.

### [Crop Water Stress Prediction](https://github.com/Anass-Erf/MLOPS_Project)

Next-day prediction of a **modeled wheat water-stress index** using NASA POWER weather and assumed soil scenarios—not field-measured crop stress.

- **Stack:** scikit-learn · MLflow · FastAPI · Docker · DuckDB · dbt · Dagster
- **Engineering:** Uses chronological evaluation, compares against a persistence baseline, and records model runs and data provenance in MLflow; includes an optional dlt → DuckDB → dbt DataOps workflow.

### [CarPrice AI](https://github.com/Anass-Erf/CarPrice-AI)

Moroccan used-car price estimation in MAD, connecting a trained regression pipeline to a web application.

- **Stack:** XGBoost · scikit-learn · FastAPI · Pydantic · Next.js · TypeScript
- **Engineering:** Preserves the original preprocessing pipeline, validates brand/model combinations against its catalog, and separates offline training from inference.
